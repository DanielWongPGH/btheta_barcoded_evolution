# B. thetaiotaomicron Barcoded Evolution

Code, processed data, and analysis notebooks associated for the paper: "High-resolution lineage tracking of within-host evolution and strain transmission in a human gut symbiont across ecological scales" ([bioRxiv preprint](https://www.biorxiv.org/content/10.1101/2024.02.17.580834v1.abstract))

Associated raw barcode, isolate whole genome, and population/metagenomic sequencing data is deposited on the SRA, BioProject accession [PRJNA1111532](https://www.ncbi.nlm.nih.gov/bioproject/?term=PRJNA1111532).


## Repository structure

- `raw_processing/` — preprocessing workflows for barcode sequencing, isolate sequencing, and metagenomics. This processing takes a ~day with access to ~dozens of cores.
- `methods/` — standalone shared Python package used by preprocessing scripts and notebooks
- `notebooks/` — analysis and figure-generation notebooks
- `data/` — populated by output of process_data, and intermediate analysis files generated by `notebooks/`
- `figures/` — generated figure files

## Environment

The local analysis environment uses Python 3.9 and is described in `environment.yaml`.

Create the environment with Conda:

```bash
conda env create -f environment.yaml
conda activate btheta-barcoded-evolution
```

Install the repository package once in that environment so `methods` is
available to scripts and notebooks regardless of the working directory:

```bash
python -m pip install -e .
```

## Configuration

Project paths are defined in `project_config.yaml`. Update the system-specific entries before running analyses.

Python code can load the configuration through `project_config.py`. Bash workflows can load the same configuration with:

```bash
source ./load_project_config.sh
```

## Data processing

The repository separates upstream processing from downstream analysis:

- `raw_processing/process_barseq/` — barcode sequencing
- `raw_processing/process_isolates/` — isolate sequencing
- `raw_processing/process_metagenomics/` — metagenomic sequencing
- `notebooks/` — downstream calculations, analyses, and plotting

The raw fastq files sum to ~hundreds of GBs, and raw processing can take ~hours to days with access to ~dozens of cores.

Isolate and metagenomic sequencing analyses also require genome sequence data for B. theta VPI-5482, to be collected in `data/reference_genome'. FASTA and ptt files can be found [here](https://www.ncbi.nlm.nih.gov/datasets/genome/GCF_000011065/). Polysaccharide utilization locus (PUL) analysis relies on a list of putative PULs in B. theta VPI-5482 collected in Table S3 of [Martens et al. (2008)](https://www.cell.com/fulltext/S1931-3128(08)00303-X). The pre-deposited file `data/reference_genome/BtVPI_plausible_inverted_repeats.txt` is a list of putative inverted repeats in the genome, was generated with einverted function of the [EMBOSS](http://emboss.open-bio.org/) software.
